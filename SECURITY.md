# Security Policy

## Supported Versions

We actively provide security updates for the following versions of the platform:

| Version | Supported |
| :--- | :--- |
| v1.x | ✅ Yes |
| < v1.0 | ❌ No |

---

## Reporting a Vulnerability

If you discover a security vulnerability, please do not file a public issue on GitHub. Instead, report it to the core development team following these steps:

1.  **Draft Report**: Prepare a details packet including:
    *   Description of the potential vulnerability.
    *   Steps to reproduce (a proof of concept).
    *   Potential impact assessment.
2.  **Submit Privately**: Send the packet via email to **sankalp.club.kmce@gmail.com**.
3.  **Triage SLA**: The core maintainers will acknowledge receipt of the report within **48 hours** and coordinate a detailed investigation.
4.  **Coordinated Disclosure**: We aim to resolve vulnerabilities within **30 days** of triage and will publish updates alongside security advisories in our release logs.

Thank you for helping keep the Sankalp Scoreboard secure for all student-athletes and organizers!
